# StudentEase

StudentEase is a calm student productivity and wellness dashboard prototype for a hackathon demo.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal. The production check is `npm run build`; linting is `npm run lint`.

## Included

- Mock login persisted in `localStorage`
- Dashboard with task, study-hour, upcoming-work, and wellness summaries
- Task creation, filtering, completion, and deletion
- Daily mood and stress check-in with suggestions
- Habit streak view
- Weekly study planner with draggable-state timetable styling
- Profile and logout
- Framer Motion cursor with spring trail, card/action/drag/text states, click ripples, touch fallback, and reduced-motion fallback

Data keys used by the demo are `user`, `tasks`, `wellness`, and `habits`.
